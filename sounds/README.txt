DOSSIER DES SONS
================

Deux possibilites :

1. Vous debutez : lancez SoundX, menu "Fichier > Ouvrir le dossier des sons"
   (il s'ouvre dans %LOCALAPPDATA%\SoundX\sounds, un emplacement stable qui
   n'est JAMAIS efface par une recompilation). Deposez-y vos fichiers, puis
   "Rescanner".

2. Vous voulez garder les sons a cote du projet : deposez-les ICI, dans ce
   dossier, AVANT le tout premier lancement. SoundX le detectera et s'en
   souviendra.

A tout moment : menu "Fichier > Choisir le dossier des sons..." pour pointer
SoundX vers n'importe quel dossier. Le choix est memorise dans
%LOCALAPPDATA%\SoundX\soundx-config.json.

Formats reconnus : .wav  .mp3  .aif  .aiff  .au
